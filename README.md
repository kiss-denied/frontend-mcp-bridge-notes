# 把自己的前端接到 ChatGPT：MCP Bridge 实践笔记

一份自建前端联动实践：让自建前端与 ChatGPT 官方客户端，通过 MCP 读取同一套状态、执行经过授权的操作。

这份仓库面向想做类似联动的朋友，分享结构、权限设计、连接流程和踩坑经验。这里只发布文档；完整应用源码、私人数据与运行配置不在本仓库中。

**记录日期：2026-10-08。ChatGPT 路径已实际验证；Claude 路径为官方文档支持的可行方向，尚未在本项目中验收。**

## 先理解我们接的是什么

前端负责展示和交互，后端负责数据与权限。我们在后端增加一层 MCP Bridge，把允许使用的能力包装成工具，让官方客户端也能使用。

```mermaid
flowchart LR
    UI["自己的前端"] <-->|原有接口| Backend["共享后端 / 数据库"]
    Backend <-->|权限检查与业务操作| Bridge["MCP Bridge"]
    Bridge <-->|受支持的连接方式| Client["ChatGPT / 其他 MCP 客户端"]
```

例如，前端修改备注后，ChatGPT 下一次调用工具能够读到新值；ChatGPT 通过工具留下日记小纸条后，前端从同一份状态显示它。

**“可读取”不等于“持续监听”。** 模型通常在会话中调用工具才会获得状态。前端事件不会因为接上 MCP，就自动唤醒官方聊天里的模型。持续任务与主动通知需要另外设计，并确认客户端支持。

## 已经做到了什么

| 能力 | 做法与验证范围 |
| --- | --- |
| 家中状态 | 一次工具调用返回允许查看的状态概览 |
| 双方备注 | 读取和修改同一份后端数据；用户已确认官方客户端写入后前端显示变化 |
| 日记 | 按身份和共享权限读取，允许在有权限的日记下留小纸条 |
| 一起听歌 | 返回音乐状态、排队与控制请求；是否真的播放以播放器反馈为准 |
| 启动连接 | 本机一键启动或复用后端与隧道，另有检查和停止入口 |

这张表描述应用层能力。聊天模型如何选择工具、是否调用、是否请求用户确认，由客户端和当前会话决定。

## 两个重要设计

### 同一份状态，明确的身份

前端与 MCP 操作同一套业务数据。数据库是实时状态的依据；长期记忆文档可以辅助理解背景，但不充当“现在正在播放什么”的证据。

后端将每条连接绑定到具体身份，并在每次调用时检查权限。不能让模型自己传一个名字，就获得那个身份的私人数据。接入第二个模型时，也要决定它对应哪个身份、可以访问哪些内容。

### 日记“共享”和“分享”分开

- **共享**：作者选中某个对象，授予持续读取权限。对方可以选择查看，也可以不看；不会自动把正文发到聊天窗。
- **分享**：作者手动将日记发送到指定聊天，内容进入当前会话上下文。

两种授权分别管理。如果取消了持续共享，但某个聊天分享仍有效，相关读取权限可能仍存在；界面应说明授权来源并允许分别撤销。已经进入聊天历史的正文也不会因撤销授权自动消失。

## 从哪里开始

1. 盘点前端现有后端、数据库和权限，先选几个小能力。
2. 把这些能力做成 MCP 工具：先读取，再做有限写入。
3. 本机验证 MCP 协议、身份与拒绝未授权访问。
4. 按客户端支持的方式连接，验证实际工具调用。
5. 做双向验收：客户端写入、前端显示；前端修改、客户端再次读取。
6. 最后处理启动、停止、状态检查和断线恢复。

我们先完成本机 Bridge，再使用 OpenAI Secure MCP Tunnel 接入 ChatGPT。隧道用于连接位于防火墙后的 MCP 服务，可以避免为这条路径另行配置公网入口。具体配置、组织与工作区权限以 [OpenAI 官方隧道文档](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)为准。

## Claude 能接吗？

**同一套 MCP 能力可以作为复用的基础，但连接方式需要另选。**

| 目标 | 可尝试的路径 |
| --- | --- |
| Claude Desktop 本地使用 | 配置受支持的本地 MCP 服务，例如 stdio 适配器 |
| Claude 网页端 / 移动端等远程连接 | 提供 Anthropic 云端可访问的远程 MCP 服务，并配置适当认证 |
| 复用 OpenAI Secure MCP Tunnel | 本项目没有验证；不能把 OpenAI 的隧道标识当作 Claude 通用地址 |

远程连接即使从 Claude Desktop 添加，也由 Anthropic 云端访问服务；本机的 localhost 地址不能直接作为这个远程入口。详见 [Claude 官方远程连接说明](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)及本仓库的 [Claude 接入说明](claude.md)。
